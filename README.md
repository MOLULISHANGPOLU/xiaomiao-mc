# 小喵 · Minecraft AI 语音陪玩（开源版）

<p>一个能说、能听、能打字的 AI 伙伴住在你的《我的世界》里：你喊一声「小喵」或者在聊天框打字，它会用语音回话、帮你砍树挖矿打怪、记住你告诉它的每一件事。</p>

> **懒人通道：把这个仓库给你常用的 AI 助手（Codex / Cursor / 豆包 / Claude / DSH 都行），说一句「读 AGENTS.md，照做」，剩下的它会自己干。**
> 你只需要在它问的时候回答几个问题、亲手装一两个软件。

---

## 两种玩法

| | 纯文字版（推荐先跑这个） | 完整语音版 |
|---|---|---|
| 怎么交流 | 游戏聊天框打字 | 直接说话，它开口回 |
| 要装什么 | 什么都不用多装 | 虚拟声卡 + 230MB 语音模型 |
| 翻车率 | 极低 | 稍高（涉及声卡路由） |
| 怎么切 | `config.json` 里 `features.voice=false` | `features.voice=true` |

## 它能干什么

- **说话/打字都行**：喊唤醒词「小喵」开口聊天，或聊天框打 `<你的游戏名> 消息` 直接下指令。
- **本地固定指令 0 花费**：跟着我、停下、给我东西、合成、查背包、切创造……20 多条本地直通，不走 API。
- **真的会动手**：AI 写进指令的行动（砍树 `#mine`、跟随 `#follow`、走到坐标 `#goto`）由 Baritone 真实执行；战斗由自研 mewfight 模组自动瞄准挥剑。
- **长期记忆**：告诉它的约定、喜好、坐标会存进本地记忆库（`1-程序\大脑\ai-memory\`），下次开机还认得你。
- **透明花费**：每一次 API 调用都记账（`--usage` 可查），不会偷偷吃 token。

## 手动安装（不用 AI 的话，跟着做）

1. 装 [Node.js](https://nodejs.org)、Java（客户端 25 / 服务端 21+）、PCL2 启动器（搜索引擎搜「PCL2」）与《我的世界》26.1.2 + Fabric。
2. 建一个 Fabric 服务端，`server.properties` 里开 RCON（小喵靠它发指令）。
3. 复制 `交付\` 三个文件夹里的 mods 到对应位置。
4. 打开 `config.json` 按注释填路径和你的游戏名。
5. 打开 `1-程序\大脑\voice-ai.json` 填 API 密钥（`sk-` 开头，任何 OpenAI 兼容接口都行）。
6. 双击 `1-程序\大脑\启动小喵.cmd`（一键：服务器 + 小喵身体 + 大脑）。
7. 进游戏，在聊天框打 `<你的游戏名> 你好` 验证。
8. 【语音版】另见 `AGENTS.md` 第 2.4 节：装 VB-Cable（要重启）、下语音模型、填三个语音路径。

## 常见问题

报错先查 [TROUBLESHOOTING.md](TROUBLESHOOTING.md)。其余：

- **会泄露我的密钥吗？** 本仓库所有配置都是占位符；你的 key 只存在你自己电脑的文件里。红线第 1 条也要求你的 AI 永不提交填好的配置。
- **要花多少钱？** 模型按量计费，日常闲聊每天几毛到几元不等，`node 1-程序\大脑\voice-ai.cjs --usage` 随时看账本；本地固定指令完全免费。
- **能改名字/人设吗？** 人设、唤醒词、说话长度全在 `voice-ai.json`；小喵身体的游戏名固定为 `LittleMew`（改名需重编译模组）。
